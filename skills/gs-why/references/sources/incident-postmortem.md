# Incident & Postmortem Context

- **Issue tracker** (Linear, Jira, GitHub Issues): look for tickets labeled `incident`, `sev-*`, `postmortem-action-item`, `reliability`
- **Team chat** (Slack, Discord, Teams): search `#sev-*` and `#incident-*` channels around the dates the target code was added
- **Git**: commits with messages like "fix for incident", "add defensive check", "revert" followed by "re-apply with..." are strong signals
